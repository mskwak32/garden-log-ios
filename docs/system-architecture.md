# 텃밭 일기 iOS 시스템 아키텍처

## 문서 목적

현재 구현에 실제로 적용된 구조와 중요한 기술 결정을 기록합니다. 예정 사항은 확정된 구조처럼 작성하지 않습니다.

## 제품 범위

- 식물 등록·조회·수정·삭제와 물주기 상태 관리
- 식물별 성장 일기와 사진
- 물주기 알림
- 일기 PDF 생성과 파일 관리
- 한국어·영어·일본어
- 설정과 선택적인 분석·오류 수집

Android 앱은 기능과 데이터 의미의 참고 자료이며, iOS 구현은 Apple 플랫폼의 관례와 제약을 따릅니다.

## 현재 확정된 기반

| 항목 | 현재 상태 |
|---|---|
| 앱 형식 | iOS 네이티브 앱 |
| UI | SwiftUI |
| Xcode 타깃 | 단일 App Target |
| 지원 기기 | iPhone·iPad로 생성됨, 최종 범위 미결정 |
| 최소 버전 | iOS 26.5로 생성됨, 최종 값 미결정 |
| 저장 | 미결정 |
| 외부 의존성 | 없음 |

## 현재 실행 구조

```mermaid
flowchart LR
    APP["@main App"] --> SCENE["WindowGroup"]
    SCENE --> VIEW["ContentView"]
    VIEW --> SWIFTUI["SwiftUI 화면"]
```

기능, 상태, 저장 계층은 실제 요구가 생길 때 경계를 정합니다. Android의 다중 모듈·MVI·DI 구조를 초기부터 그대로 복제하지 않습니다.

## 아키텍처 갱신 기준

- 실제로 채택한 기술과 계층만 추가합니다.
- 데이터 흐름, 저장 경계, 파일 소유권, 알림 책임처럼 여러 기능에 영향을 주는 결정을 기록합니다.
- 화면별 세부 구현이나 작업 진행 상황은 기록하지 않습니다.
