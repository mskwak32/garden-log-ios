# 텃밭 일기 iOS 작업 계획

## 문서 목적

완성까지의 장기 방향을 작업 단위로 관리합니다. 기간이 아니라 독립적으로 확인 가능한 결과를 기준으로 나눕니다.

작업 단위 원칙:

- 사용자에게 보이는 결과 또는 중요한 기술 경계 하나를 완성합니다.
- 별개의 사용자 흐름이나 기술 경계가 둘 이상이면 나눕니다.
- 독립적인 결과나 학습 내용이 없는 작은 설정 변경은 인접 단위에 합칩니다.
- 난이도 차이는 허용하되 서로 독립적인 결과가 한 문서에서 이해하기 어려울 정도로 섞이면 작업 단위를 분할합니다.
- 테스트는 각 단위에서 필요한 동작만 다루며, 별도 테스트 작업을 관성적으로 추가하지 않습니다.

## 장기 계획

### 1. 개발 기반

- [ ] **00. 프로젝트 기반 확인** — 기본 앱 실행, 생성 파일 이해, 지원 기기와 최소 iOS 버전 결정
- [ ] **01. Swift와 SwiftUI 화면 구성** — 값과 타입, `View`, modifier, Preview를 사용해 첫 정적 화면 구성
- [ ] **02. 앱 뼈대와 내비게이션** — 식물·일기·설정 탭과 화면 이동 구조 완성

### 2. 식물 관리

- [ ] **03. 식물 모델과 목록** — 메모리 데이터로 식물 모델, 목록, 빈 상태 표현
- [ ] **04. 식물 등록과 수정** — 입력 폼, 바인딩, 검증, 저장·취소 흐름
- [ ] **05. 식물 상세와 상태 변경** — 상세 화면, 물주기, 수확 상태, 삭제 확인
- [ ] **06. 로컬 저장** — 저장 기술 결정, 스키마 구성, 식물 CRUD 연결
- [ ] **07. 식물 사진** — 카메라·사진 보관함 권한, 선택, 저장과 표시

### 3. 성장 일기

- [ ] **08. 일기 모델과 조회** — 식물과 일기의 관계, 목록과 상세 화면
- [ ] **09. 일기 작성과 수정** — 날짜·내용 입력, 검증, 저장과 삭제
- [ ] **10. 일기 사진** — 여러 사진의 선택, 관계, 저장과 표시
- [ ] **11. 정렬과 필터** — 날짜·식물 기준 정렬 및 필터 상태 관리

### 4. iOS 기능

- [ ] **12. 물주기 알림** — 권한 요청, 알림 예약·변경·취소, 앱 상태와 동기화
- [ ] **13. 일기 PDF 생성** — 식물별 일기를 문서로 구성하고 PDF 생성
- [ ] **14. 내보낸 파일 관리** — 파일 목록, 미리보기·공유·삭제
- [ ] **15. 다국어와 접근성** — 한국어·영어·일본어, VoiceOver, 동적 글자 크기 점검

### 5. 완성도와 배포

- [ ] **16. 설정과 운영 도구** — 앱 설정, 분석·오류 수집 도입 여부 결정 및 적용
- [ ] **17. 출시 준비** — 핵심 흐름 점검, 데이터 변경 대응, 서명과 App Store 제출 준비

## 결정 지점

결정 전에는 구현에서 전제하지 않습니다.

| 시점 | 결정할 내용 |
|---|---|
| 00 | iPhone 전용 여부, 최소 iOS 버전, Bundle Identifier |
| 02 | 탭별 내비게이션 구조와 화면 소유권 |
| 06 | 저장 기술, 스키마 변경과 마이그레이션 원칙 |
| 07 | 사진 파일 저장 위치와 삭제 정책 |
| 12 | 알림 시각·반복·권한 거부 시 동작 |
| 16 | 분석·오류 수집 서비스와 개인정보 범위 |
| 17 | 배포 대상, 버전 정책, App Store 공개 범위 |

작업을 진행하며 실제 난이도가 드러나면 단위를 분할하거나 합칠 수 있습니다. 변경 이유만 이 문서에 짧게 남깁니다.
